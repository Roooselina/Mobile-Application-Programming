# AI 오늘의 말투 변환기 — 기능 설명서

상황과 상대에 맞는 말투로 메시지를 변환해주는 앱입니다.
현재 구현되어 있는 기능을 화면별로 정리했습니다.

---

## 1. 계정

### 회원가입
- 이름 / 이메일 / 비밀번호(6자 이상) / 비밀번호 확인 입력
- **이메일 인증 필수**: [인증요청] 버튼 → 입력한 메일로 6자리 인증코드 발송 → 코드 입력 후 [확인]
  - 코드는 **5분간 유효**, 1회용
  - 인증 후 이메일을 수정하면 인증이 무효화되어 다시 받아야 함
  - 이미 가입된 이메일이면 코드 발송 전에 알려줌
- 가입 시 입력한 **이름**이 앱 전체의 기본 이름으로 사용됨
- 비밀번호는 원문이 아닌 **SHA-256+솔트 해시**로 저장 (DB가 유출돼도 비밀번호를 알 수 없음)

### 로그인
- 이메일 + 비밀번호 로그인
- **비밀번호를 잊으셨나요?**: 가입 이메일로 인증코드 발송 → 코드 확인 후 새 비밀번호 설정

### 내 정보 (프로필 메뉴)
- **내 정보 수정 (계정정보)**: 이름 / 이메일 / 닉네임 수정
  - 이름을 수정하면 이후 기본 이름으로 수정된 이름이 사용됨
  - **비밀번호 변경**도 이 화면에서: 현재 비밀번호 확인 후 새 비밀번호로 변경
- **로그아웃**

## 2. 프롬프트 (대화 상대별 말투 설정)

### 새 프롬프트 생성 — 2단계 팝업
뒤 배경이 어두워지고 카드만 뜨는 팝업 형식.

- **1단계**: ① 대화 상대(필수) ② 그룹(선택 — 직장/학교/가족 등) ③ 나에 대한 정보(선택)
  - **나에 대한 정보를 비워두면** 설정의 사용자 프로필 → 그것도 없으면 계정 이름이 자동 사용됨 (안내문에 실제 사용될 이름 표시)
- **2단계**: 말투 키워드 선택(최대 5개, 직접 추가 가능) + 반드시 기억해야 할 정보(선택)
- 생성하면 **방금 만든 프롬프트의 대화창으로 바로 이동**

### 프롬프트 설정 보기/수정 — 팝업
- **대화창 상단 제목(연필 아이콘)을 누르면** 이 대화에 적용 중인 설정 전체를 한눈에 확인하고 바로 수정 가능
  - 대화 상대 / 그룹 / 나에 대한 정보 / 말투 키워드 / 기억할 정보
- 사이드바 ⋮ 메뉴의 **수정**으로도 열 수 있음

### 사이드바 (프롬프트 목록)
- **즐겨찾기** 섹션 + **그룹(폴더)별 섹션** + 미분류(최근) 순으로 정리되어 표시
- 프롬프트별 ⋮ 메뉴: 즐겨찾기 추가/해제, 수정, 삭제
- 검색 화면에서 프롬프트 검색 가능
- 화면 왼쪽 가장자리 스와이프로 사이드바 열기/닫기

## 3. 대화 (말투 변환)

### 기본 변환
- 메시지를 입력하고 전송하면, 프롬프트 설정(상대/키워드/나에 대한 정보/기억 정보)과
  **이전 대화 맥락**을 반영해 변환된 메시지를 돌려줌
- 호칭·말끝·서명을 이전 대화와 **일관되게 유지**
- 변환 중 ··· 입력 표시

### 실시간 변환 미리보기 *(설정에서 켜기)*
- 입력을 멈추면 1.2초 뒤 자동으로 변환 결과를 입력창 위에 미리 보여줌
- 미리보기 상태 그대로 전송하면 **API 재호출 없이 즉시** 그 결과가 사용됨

### 변환 결과 (AI 답변)마다 가능한 것
**제스처**
- 답변 칸을 **오른쪽→왼쪽으로 밀면** 새 답변(다른 버전) 생성
- 답변 칸을 **꾹 누르면** 그 답변을 내가 직접 수정 → 수정본이 새 버전으로 그 자리에 저장 (AI 재호출 없음)

**답변 아래 미니멀 아이콘 줄**
- **◀ 1/3 ▶**: 생성된 버전들을 좌우로 넘기며 확인 (선택한 버전이 이후 대화 맥락에도 사용됨)
- **🔄 재생성 아이콘**(원형 화살표+반짝이): 다른 버전 생성
- **👍 / 👎 라인 아이콘**: 피드백 저장. 👎를 누르면 "다른 버전을 만들까요?" 제안
- **복사 / 공유 아이콘**
- **더보기/접기**: 긴 답변은 8줄까지만 보여주고 펼치기 가능

### 입력 편의
- **최근 입력**(입력창 왼쪽 시계 버튼): 이 대화에서 보냈던 최근 입력 10개 목록 → 탭하면 입력창에 채워짐
- **드래프트 자동 저장**: 쓰다 만 내용은 프롬프트별로 자동 저장, 앱을 껐다 켜거나 다른 대화에 다녀와도 복원
- **백그라운드 변환**: 변환 대기 중 다른 프롬프트로 이동해도 결과는 유실되지 않고 저장되며, 완료 알림 표시

## 4. 앱 설정

- **화면 모드**: 시스템 / 라이트 / 다크 — 전환 시 번쩍임 없는 부드러운 페이드 효과
- **글자 크기**: 4단계
- **AI 설정**: 기본 변환 강도(원문 최대 유지/균형), 응답 길이(짧게/보통/자세하게), **실시간 변환 미리보기 켜기/끄기**
- **사용자 프로필**: 이름/소속/직책 저장 → 프롬프트의 '나에 대한 정보'가 비었을 때 기본값으로 사용. 이름이 비어 있으면 계정 이름이 기본으로 표시됨
- **특정 표현 금지**: 결과에 쓰지 않을 표현 등록

---

## 5. UI / 기타

- 입력칸 힌트는 본문보다 작은 글자(12sp)로 표시되어 화면이 깔끔함
- 팝업 화면(생성/수정)은 페이드 전환, 일반 화면은 슬라이드 전환
- 다크 모드 완전 대응

## 설정 파일 (개발자용)

`local.properties`:
```
ANTHROPIC_API_KEY=...      # 변환 API 키
SMTP_EMAIL=...             # 인증 메일 발신 Gmail 주소
SMTP_PASSWORD=...          # Gmail 앱 비밀번호 16자리
```
- SMTP 설정이 비어 있으면 인증코드는 **데모 모드**(화면에 코드 표시)로 동작
- 이 파일은 깃에 올라가지 않음 (.gitignore 기본 포함)
